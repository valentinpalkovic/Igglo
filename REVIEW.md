# Review suppression list

Reviewers (Reviewer Sol, Reviewer Opus, QA) read this file before every review
and do not flag what is listed here. See the iglo-handbook, Code review,
"Suppression list and learning loop".

How an entry gets here: the author rejects a finding with a reason, the Staff
Engineer agrees, and the QA Engineer adds one line: what not to flag, and why.
Link the PR where it was decided.

Format: `- <what not to flag>: <why> (<PR link>)`
